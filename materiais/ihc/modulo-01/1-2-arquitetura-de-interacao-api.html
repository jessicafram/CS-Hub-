1.2 Arquitetura de Interação

O impacto da escolha da interface (Web vs. Voz) na modelagem do Backend e APIs.

No design de sistemas em nível de arquitetura, a Interação Humano-Computador não dita apenas a cor do botão ou a tipografia da tela. A escolha do paradigma de interface muda radicalmente o custo computacional, a modelagem do banco de dados e o formato das APIs.

1. Interfaces Gráficas (Web/Mobile) vs Carga de API

Quando projetamos uma GUI (Graphical User Interface) tradicional, como um dashboard web, a interação humana é baseada em Reconhecimento Visual. O usuário precisa de opções na tela para clicar.

Arquiteturalmente, isso significa que nosso backend via REST ou GraphQL precisa entregar grandes cargas de dados (Payloads maiores) para preencher combos, tabelas e menus. A carga de "filtragem" e estado fica majoritariamente no front-end (React/Vue) ou no banco de dados com buscas paginadas.

2. Interfaces de Voz (VUI) e Agentes de IA

Quando migramos para Interfaces Conversacionais (VUI - Voice User Interface) ou Agentes de Inteligência Artificial processados no n8n, o paradigma muda para a Recordação e Intenção.

O usuário não clica em um menu "Sapatos > Tênis > Preto". Ele envia um áudio dizendo: "Quero um tênis de corrida preto tamanho 40".

O Paradoxo da Interface de Voz

Para o usuário, a interface de voz tem carga cognitiva quase zero (é a forma mais natural de comunicação). Porém, para o sistema, ela gera uma carga de processamento assustadora (NLP - Processamento de Linguagem Natural, extração de intenções, RAG e chamadas a modelos como OpenAI/Gemini).

3. Modelagem de APIs para Interfaces Conversacionais

Enquanto uma API REST comum para um site retorna um array de objetos complexos, a integração de um Agente de IA com o seu banco de dados precisa ser projetada para buscar apenas os dados exatos (RAG - Retrieval-Augmented Generation) para não estourar os tokens da LLM.

// Exemplo: O que uma interface Web pede GET /api/produtos?categoria=tenis&cor=preto // Exemplo: O que um Agente de IA no n8n extrai do áudio { "intent": "purchase_search", "entities": { "product": "tênis de corrida", "color": "preto", "size": 40 }, "confidence": 0.98 }

Conclusão do Tópico

Como Arquitetos de Software e Especialistas em UX, nosso papel não é apenas desenhar a interface mais bonita, mas decidir onde o esforço computacional deve morar. Interfaces invisíveis (Zero-UI) e bots conversacionais transferem o esforço cognitivo do cérebro humano para o processador do servidor.
