Aula 03: Lógica de Fluxo Avançada — Loops e Switches

Aprenda a dar inteligência decisória ao seu robô e a processar listas gigantescas de dados sem perder nenhuma informação.

Introdução: O Robô que Pensa e Repete

1. O que é o nó Switch? (A Analogia da Triagem do Hospital)

Imagine a recepção de um pronto-socorro. O paciente chega e pega uma senha.

  • O Problema: Se todos entrarem na mesma fila, quem está apenas com tosse pode atrasar o atendimento de quem chegou infartando.
  • A Triagem (O Switch): A enfermeira avalia o paciente. Se for grave, ela manda para o "Caminho 1" (Emergência). Se for leve, manda para o "Caminho 2" (Ambulatório).

No n8n: O nó Switch é a nossa enfermeira. Ele lê o JSON da Aula 02 e decide para qual caminho o fluxo deve seguir com base em regras que você cria.

2. O que é um Array? (A Analogia da Caixa de Fichas)

Na Aula 02, aprendemos que o JSON é uma "Ficha de Correio".

  • O Problema: Se você vender 100 produtos no dia, você não recebe 100 e-mails separados simultaneamente. Você recebe um relatório com as 100 vendas agrupadas.
  • O Array (A Lista): Um Array é como se fosse uma "Caixa de Sapato" onde você guarda as 100 Fichas de Correio lá dentro.

No n8n: Quando a saída de um nó diz `100 items`, significa que ele está segurando uma Caixa (Array) com 100 Fichas (Objetos JSON).

3. O que é o nó Loop? (A Analogia do Carimbador)

O que acontece quando você entrega a Caixa com 100 fichas para o sistema processar?

  • O Problema: Sistemas burros tentam processar as 100 de uma vez, travam e deixam cair informações.
  • O Carimbador (O Loop): É um funcionário focado. Ele pega a Caixa de Fichas. Tira a primeira ficha, envia a mensagem no WhatsApp, e guarda a ficha. Tira a segunda, envia a mensagem, e guarda. Ele repete o ciclo (Loop) até a caixa esvaziar.

No n8n: O nó Loop garante que ações individuais (como mandar e-mail) sejam executadas com perfeição para cada item da sua lista, um por um.

Bloco 1: A Teoria que Sustenta o Prédio

Objetivo: Entender a matemática e a lógica booleana por trás das decisões.

1.1 Roteamento Condicional (Lógica Booleana)

O Conceito: Computadores só entendem "Verdadeiro" (True) ou "Falso" (False). Quando usamos o nó Switch, estamos criando comparações lógicas matemáticas.

As Regras (Operadores): Nós dizemos ao robô: "Verifique se o valor X é Igual a, Maior que, ou Contém o valor Y". Se a resposta for sim (True), o dado desce por aquele cano.

1.2 Iteração (A Força Bruta do Software)

O Conceito: Iterar significa "repetir um processo sobre uma lista de dados". Essa é a maior vantagem dos computadores sobre os humanos. Um robô não cansa de enviar 5.000 e-mails idênticos.

Na Prática: Se você tentar ligar o Google Sheets (que gera 100 clientes) direto no nó do Gmail, ele tentará mandar um e-mail gigantesco para 100 pessoas no mesmo campo. O Loop quebra essa ação em 100 e-mails bonitos e individuais.

⚠️ A Regra de Ouro do Loop: O fluxo que sai do nó Loop precisa voltar para ele no final da tarefa. É esse "retorno" que avisa o n8n: "Terminei de carimbar essa ficha, me dê a próxima!".

Bloco 2: Laboratório Prático

Objetivo: Criar uma "Régua de Relacionamento" usando lógica visual no canvas.

2.1 Construindo a Triagem (Nó Switch)

O Desafio: Receber um banco de dados de clientes e separar os clientes "VIP" dos "Comuns".

A Ação: Adicionamos o nó Switch e criamos as rotas.
Rota 0: Se o `status_cliente` for igual a `VIP`.
Rota 1: Se o `status_cliente` for igual a `Comum`.

O Resultado: Você verá visualmente o seu JSON "se dividindo" em duas saídas diferentes no canvas, permitindo que você aplique descontos diferentes para cada grupo.

2.2 Configurando o Carrossel (Nó Loop)

O Desafio: Mandar uma mensagem individual para os 5 clientes VIP que saíram da Rota 0 do Switch.

A Ação: Conectamos a saída 0 do Switch na entrada do Loop. Depois do Loop, colocamos um nó de ação (ex: enviar mensagem). O pulo do gato é arrastar a bolinha de saída do nó de mensagem e ligar de volta na entrada do Loop.

A Visão do Arquiteto: Se o nó falhar durante o Loop (ex: o cliente número 3 estava sem e-mail), você pode configurar as opções de erro para "Continuar". Assim, o robô reporta o erro do cliente 3, mas continua e entrega os e-mails 4 e 5 intactos.

Bloco 3: Estudo de Caso Clínico - O Cérebro da IA

A Triagem Inteligente

Imagine o fluxo de WhatsApp de uma grande clínica médica. O cliente envia uma mensagem solta: "Quero cancelar minha consulta de amanhã".

  1. Entrada: O n8n recebe o WhatsApp.
  2. Classificação: O n8n envia a mensagem para a IA e pede: "Leia este texto e me retorne apenas uma palavra: MARCAR, CANCELAR ou DUVIDA."
  3. O Retorno JSON: A IA devolve: { "intencao": "CANCELAR" }.
  4. O Switch (A Mágica): Nós colocamos um nó Switch para ler a chave intencao. Como a palavra é CANCELAR, o fluxo é desviado imediatamente para a automação que libera a agenda do médico, sem intervenção humana.

📝 Exercícios de Fixação

Antes de abrir o gabarito na Apostila de Mentoria, reflita e tente responder a estas três perguntas:

  1. Switch vs Lógica Humana: Por que usamos o nó Switch no lugar de criar 5 robôs (fluxos) diferentes para cada status de cliente?
  2. A Ficha e a Caixa: Qual é a diferença prática entre processar um JSON "Objeto" (uma ficha) e um JSON "Array" (uma caixa de fichas)?
  3. A Regra do Loop: O que acontece com a automação se você esquecer de ligar a saída da última tarefa de volta para a entrada do nó Loop?

📚 Apostila de Mentoria

Expanda os tópicos abaixo para acessar o dicionário e o gabarito.

▶ 📖 1. O Dicionário da Lógica de Fluxo
Termo Técnico Analogia do Mundo Real No n8n
Array (Lista) A Caixa contendo várias Fichas. Vários objetos agrupados indicados por colchetes [ ].
Switch (Roteamento) A Triagem do Hospital / Cancelas de Pedágio. Nó que testa condições e desvia os dados para saídas diferentes.
Loop (Iteração) O Carimbador metódico e infinito. Nó que pega um Array grande e processa item por item até acabar.
▶ ✅ 2. Checklist do Arquiteto (Antes do Play)
  • 🔲 As rotas estão nomeadas? As regras do seu Switch são fáceis de ler (ex: 'É VIP') ou genéricas (ex: 'Regra 0')?
  • 🔲 O Loop está fechado? A linha tracejada da última ação volta para o nó Loop?
  • 🔲 Fallback configurado? O seu nó Switch tem uma rota padrão (Fallback) caso o dado do cliente venha vazio ou desconhecido?
▶ 🎯 3. Gabarito dos Exercícios de Fixação

1. Switch vs Lógica Humana: Usar um único fluxo com um nó Switch centraliza a manutenção (SOA). Se algo mudar, você ajusta um único robô em vez de ter que reescrever 5 fluxos separados.

2. A Ficha e a Caixa: Processar a ficha (Objeto) é uma ação única. Processar a caixa (Array) exige abrir a caixa e iterar (Loop) sobre cada item, senão o sistema tenta empurrar 100 itens de uma vez no mesmo campo de destino.

3. A Regra do Loop: O robô processa o primeiro item e "morre". Como a linha não voltou para o Loop, o sistema entende que o trabalho acabou, e as outras 99 fichas ficam paradas na caixa.
