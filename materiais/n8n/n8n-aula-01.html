1. Bem-vindo à sua Transição de Carreira

Este plano foi desenhado estrategicamente para unir experiência técnica com as necessidades práticas que o mercado de Inteligência Artificial exige hoje. Nosso objetivo nesta primeira semana é preparar o seu "laboratório" de trabalho e entender como as automações pensam.

2. O Coração da Operação: Instalação via Terminal

Como especialista, você não usará apenas instaladores comuns. Aprenderemos a via profissional, que garante mais controle e estabilidade para os seus futuros Agentes de IA.

A. O Motor (Node.js)

Antes do n8n, precisamos do Node.js, o software que permite que nosso computador execute instruções complexas de automação.

  • Ação: Baixe e instale a versão LTS em nodejs.org.
  • Por que isso? O n8n é construído sobre essa tecnologia; sem ela, nossa central não liga.

B. A Instalação Profissional (NPM)

No terminal do seu computador, utilizaremos o NPM (um gerenciador de pacotes) para buscar o n8n original:

  • Comando: npm install n8n -g
  • O que significa: Estamos pedindo para o sistema baixar o n8n e deixá-lo disponível em todo o computador (-g de "Global").

C. Iniciando o n8n

Com a instalação concluída, basta digitar n8n no terminal.

  • Regra de Ouro: O terminal deve permanecer aberto enquanto você trabalha. Ele é o "servidor" que mantém sua automação viva.
  • Acesso: Abra seu navegador e digite: http://localhost:5678.

Configuração Inicial (Owner Setup)

Agora, vamos para a parte visual no seu navegador.

  • Acesse http://localhost:5678 e crie sua conta de Proprietário (Owner) com seu e-mail profissional.
  • Personalização: Responda às perguntas de perfil (Educação/Desenvolvedor) para que o n8n ajuste as sugestões ao seu uso.
  • Recursos de Elite (Licença): O n8n solicitará seu e-mail para ativar recursos avançados como Pastas e Depuração. Insira seu e-mail e clique em "Envie-me uma chave de licença gratuita".
  • Copie a chave do seu e-mail e cole no sistema. Se aparecer "chave já usada", significa que o sistema já ativou sua licença automaticamente.

3. Entendendo a Interface e o Primeiro Teste

Para iniciar a explicação teórica e prática, clique em:

Botão: Comece do zero.

O que você verá: Uma área quadriculada infinita chamada Canvas. Pense nela como a sua mesa de projetos de IA.

Teoria dos Termos Técnicos

Antes de adicionar qualquer item, entenda os quatro pilares do n8n:

  • 1- Nó (Node): É cada quadradinho que colocamos na tela. Cada um é um "especialista" em uma tarefa (ex: um nó que envia e-mails, um nó que consulta o banco de dados).
  • 2- Workflow (Fluxo de Trabalho): É o conjunto de nós conectados. É o caminho que a informação percorre para resolver um problema.
  • 3- Execução: É o ato de ligar o fluxo. Quando você clica em "Execute", você está vendo sua automação "ganhar vida".
  • 4- Parâmetros: São as configurações dentro de cada nó. É onde dizemos ao nó exatamente o que ele deve fazer.

4. Prática: Adicionando e Conectando seu Primeiro Nó

  • A Biblioteca de Nós: Clique no ícone de (+) no centro ou no canto superior direito.
  • Busca Inteligente: No campo de busca, digite Manual.
  • O Gatilho (Trigger): Selecione o nó chamado "When clicking 'Execute Workflow'".

Teoria: Este é o "botão de partida" manual. Nada acontece no n8n sem um gatilho inicial.

  • Conexão Visual: Note que o nó tem uma bolinha no lado direito. Clique nela e arraste. O n8n abrirá automaticamente a busca para o próximo nó.
  • A Ação (Action): Busque por Edit Fields.

Teoria: As ações são os "trabalhos" que o agente realiza após ser disparado. Essa tela é exatamente onde a "mágica" da configuração acontece. Ela representa o painel interno de uma Ação (Action), especificamente do nó Edit Fields (Editar Campos), onde definimos o que o agente deve fazer com os dados.

Explorando a Anatomia de uma Ação: O Nó "Edit Fields"

Após clicar em "Comece do zero" e adicionar seu primeiro nó de ação, você entrará nesta tela de configuração. Aqui é onde damos as ordens diretas para o nosso Agente de IA.

1. O Painel de Três Colunas

Esta tela é dividida logicamente para mostrar o fluxo da informação:

  • Entrada (Lado Esquerdo): Mostra os dados que estão chegando do nó anterior. Como este é o nosso primeiro teste, ele aparecerá como "Nenhum dado de entrada".
  • Parâmetros (Centro): É aqui que você trabalha. É o lugar onde configuramos as regras e os novos dados que queremos criar.
  • Saída (Lado Direito): Mostra o resultado final após o nó processar suas instruções. É o "rascunho" do que será enviado para o próximo passo do fluxo.

2. Teoria na Prática: Configurando a Ação

Os botões principais para que você perca o medo da interface:

  • Adicionar Campo (Add Field): É o botão central. Ao clicar nele, você escolhe que tipo de informação quer criar (um texto, um número, uma data).
  • Executar Etapa (Execute Step): Localizado no topo. Serve para testar apenas este nó isoladamente, sem precisar rodar o curso inteiro. Isso é o que chamamos de Depuração Avançada.

3. Por que este nó é o "Pulo do Gato"?

O nó Edit Fields é um dos mais importantes da sua carreira. Com ele, você pode:

  • Limpar dados bagunçados que vêm da internet.
  • Criar mensagens personalizadas para clientes.
  • Preparar informações antes de enviá-las para o ChatGPT ou WhatsApp.

5. O Painel de Controle (Configuração)

Um nó só funciona se for configurado:

  • Dê dois cliques no nó Edit Fields.
  • Add Field > String: No nome, coloque boas_vindas. No valor, escreva: Olá, Maurício! Este é seu primeiro agente.
  • Fechar e Salvar: Clique no "X" do painel lateral para voltar ao Canvas.

A Hierarquia do Conhecimento: Nome vs. Valor

Para que um Agente de IA funcione, Maurício, ele precisa respeitar uma hierarquia de três níveis. Sem essa estrutura, o seu fluxo é apenas um desenho, não uma ferramenta funcional.

1. O Nome (A Etiqueta / O Rótulo)

É o nível mais externo. É como você chama o nó no Canvas (ex: "Boas Vindas").

  • Para que serve: Identificação humana. Ajuda você e outros desenvolvedores a entenderem o mapa do fluxo rapidamente.
  • O erro comum: Achar que mudar o nome do nó muda o que ele faz. O nome é apenas a "casca".

2. O Parâmetro (O Campo / A Variável)

É o nível intermediário. É quando você define "o que" estamos manipulando (ex: o campo boas_vindas).

  • Para que serve: É a estrutura que recebe a informação. É a "gaveta" onde guardaremos o dado.

3. O Valor (A Essência / O Conteúdo)

É o nível mais profundo e o mais importante. É a informação real (ex: "Olá, Maurício!").

  • Para que serve: Sem o valor, o nó não tem substância. O valor é o que o Agente de IA realmente entrega para o cliente final.

Box: Fundamento Epistemológico - A Ontologia do Nó

Na filosofia, a Ontologia estuda o ser das coisas. No n8n, a ontologia de um nó completa-se apenas no Valor.

  • O Nome é o "Parecer" (como o nó se apresenta no Canvas).
  • O Valor é o "Ser" (o que o nó realmente entrega à realidade).

Um especialista sênior sabe que um fluxo elegante no Canvas (nomes bonitos) não substitui uma lógica robusta (valores precisos).

O que você encontra nesses três pontinhos:

  • Download: Permite baixar o fluxo como um arquivo .json. Isso é vital para ele fazer backups ou enviar o trabalho para você avaliar.
  • Renomear: Onde ele troca o nome do projeto (atualmente está como "Meu fluxo de trabalho").
  • Importar de arquivo: Caso ele receba um modelo seu, é por aqui que ele carrega para dentro do n8n dele.
