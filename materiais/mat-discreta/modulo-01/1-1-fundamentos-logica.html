Módulo 1: Fundamentos da Lógica

Descubra como o processador "pensa" e pare de sofrer com condicionais complexos no seu código.

Se você já escreveu um if (usuario.ativo && saldo > 0) no seu código, você já usou Matemática Discreta. A computação inteira é construída em cima de uma única premissa: as coisas são Verdadeiras (1) ou Falsas (0).

Nesta aula, vamos decodificar a linguagem da máquina: a Lógica Proposicional.

1. O que é uma Proposição?

Na lógica matemática, uma proposição é simplesmente uma frase declarativa que pode ser julgada como Verdadeira (V) ou Falsa (F), mas nunca as duas coisas ao mesmo tempo.

  • ✅ "O Brasil fica na América do Sul." (Proposição! É Verdadeiro).
  • ✅ "10 é menor que 5." (Proposição! É Falso).
  • ❌ "Qual é a sua idade?" (Não é proposição. Uma pergunta não tem valor Verdadeiro/Falso).
  • ❌ "Feche a porta do servidor!" (Não é proposição. É uma ordem).

No Código: Uma proposição é qualquer expressão que você coloca dentro de um `if`. Por exemplo: `idade >= 18` é uma proposição matemática que a CPU vai avaliar como V ou F.

2. Conectivos Lógicos (Os operadores do código)

Na vida real, nós juntamos frases simples para criar condições complexas. "Eu só vou à praia SE fizer sol E eu tiver dinheiro". Na matemática, fazemos o mesmo com Conectivos Lógicos.

Conectivo Símbolo Matemático Símbolo no Código A Regra de Ouro
Conjunção (E) P ∧ Q P && Q Só é Verdadeiro se TUDO for Verdadeiro.
Disjunção (OU) P ∨ Q P || Q É Verdadeiro se PELO MENOS UM for Verdadeiro.
Disjunção Exclusiva (XOR) P ⊕ Q P ^ Q Só é Verdadeiro se forem DIFERENTES (Um ou outro, mas não ambos).
Negação (NÃO) ~P ou ¬P !P Inverte o valor (V vira F, F vira V).

4. Implicação Lógica (Se P, então Q)

O conectivo que mais cai em provas e causa confusão é a Implicação (P → Q). Lemos como "Se P, então Q".

Pense nisso como uma Promessa de Político: "Se eu for eleito (P), então construirei um hospital (Q)".

  • Foi eleito (V) e construiu (V) = Promessa cumprida. (V)
  • Foi eleito (V) e NÃO construiu (F) = Mentiroso! É a única forma de a implicação ser Falsa. (F)
  • Não foi eleito (F) e não construiu (F) = Não mentiu, pois a condição era ser eleito. (V)
  • Não foi eleito (F) mas construiu mesmo assim (V) = Ótimo! Ele não quebrou a promessa inicial. (V)
Lembrete de Ouro 
A implicação (P → Q) SÓ É FALSA no caso:
Vera Fischer (V → F = F).
Todos os outros casos são Verdadeiros!

5. As Leis de De Morgan (Hackeando o Código)

Augustus De Morgan criou regras matemáticas que os programadores usam todo dia para simplificar lógicas confusas. Como você nega um bloco inteiro?

  • Lei 1: A negação do "E" vira "OU".
    ~(P ∧ Q) ≡ ~P ∨ ~Q
  • Lei 2: A negação do "OU" vira "E".
    ~(P ∨ Q) ≡ ~P ∧ ~Q

Exemplo Prático (De Morgan no Backend):
Seu código tem isso: if ( !(idade >= 18 && tem_ingresso) )
Aplicando De Morgan para ficar mais legível: if ( idade < 18 || !tem_ingresso )
